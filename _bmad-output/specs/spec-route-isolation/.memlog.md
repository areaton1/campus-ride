updated: 2026-11-18T12:39

- (direction) Team approved Feature 1 bus route isolation from architecture audit; implement on feature/route-isolation only.
- (capability) CAP-1: Student can isolate one bus route on the map so unrelated route lines, underlays, and bus markers are fully hidden while the selected route stays highlighted.
- (capability) CAP-2: Student can restore the full multi-route overview by re-selecting the active route or using Show All Routes.
- (capability) CAP-3: Selecting a recommended itinerary focuses the map on that itinerary route without changing itinerary calculation.
- (decision) AD-1: Introduce state.mapFocusRouteId as presentation-only view state; trip.route.id always wins while a trip is active.
- (decision) AD-2: Isolation hides path/underlay/stop/bus SVG for non-focus routes via display none; simulation loop continues updating all buses.
- (constraint) No APIs, no new deps, HTML/CSS/JS/SVG only; do not filter computePlans; out of scope: POI, pinch-zoom, location expansion.
- (event) Spec distilled for Feature 1 implementation.
